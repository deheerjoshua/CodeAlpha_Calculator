# CodeAlpha Calculator

A simple and beautiful calculator built with HTML, CSS, and JavaScript for the CodeAlpha Internship.

## Features
- Addition, Subtraction, Multiplication, Division
- Clear (C) and Delete (⌫) buttons
- Responsive design

## Live Demo
https://deheerjoshua.github.io/CodeAlpha_Calculator/

## How to Use
Click the numbers and operators to calculate.
